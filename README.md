# Sales Data Analysis

## Project Overview

This project analyzes Superstore sales data to identify sales trends, product performance, regional performance, customer segments, profitability, and the relationship between discounts and profit.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- DuckDB
- Excel
- Google Colab

## Analysis Performed

- Data cleaning and validation
- Missing-value analysis
- Duplicate-value analysis
- Exploratory Data Analysis (EDA)
- Category-wise sales analysis
- Region-wise sales and profit analysis
- Customer segment analysis
- Top product analysis
- Monthly sales trend analysis
- Discount and profit analysis
- Loss-making product analysis
- SQL-based business analysis

## Key Metrics

| Metric | Value |

## Key Business Questions

1. Which categories generate the most sales?
2. Which regions generate the most profit?
3. Which products have the highest sales?
4. How do sales change over time?
5. Which products generate negative profit?
6. How does discounting relate to profitability?

## Conclusion

The analysis provides a business-oriented view of sales performance by combining Python-based exploratory analysis, SQL queries, data visualization, and Excel reporting.
